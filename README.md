# Modern Edge Foundation

Build Phase 1 of the Modern Edge website.

Do NOT attempt to build every page yet. Focus on creating an exceptional design foundation and premium homepage.

BRAND

Company:
Modern Edge Architects and Engineers Pvt. Ltd.

Colors:

Primary blue: #004AAD

Black: #000000

White: #FFFFFF

Use a premium font such as Manrope or Inter.

Design direction:

Architectural Minimalism + Engineering Precision + Premium Corporate

The website must NOT look like a generic engineering-company template.

Avoid:

excessive rounded cards

excessive gradients

excessive shadows

childish icons

generic stock-photo layouts

fake statistics

fake testimonials

fake awards

fake certifications

Use:

large typography

generous whitespace

asymmetrical/editorial layouts

architectural geometry

subtle technical grid lines

thin borders

sophisticated hover states

restrained animation

premium spacing

Use the uploaded Modern Edge logo as the official logo.

If necessary, remove its background cleanly and create appropriate light/dark versions without distorting it.

Use the uploaded founder photographs only where appropriate later; don't force them into Phase 1.

THEME SYSTEM

Implement both:

Light Theme

White/light surfaces, black typography, #004AAD accents.

Dark Theme

Near-black/deep navy surfaces, white typography, #004AAD accents.

Dark mode must be intentionally designed, not simply color-inverted.

Add a theme switcher in the header.

Persist the user's theme preference.

Respect system theme preference initially.

HEADER

Create a premium sticky header.

Desktop:

Logo

Navigation:

Property Valuation

Construction

Services

About

Process

Founders

Reviews

Contact

Right:

Request Valuation

Theme toggle

Header should initially be transparent over the hero and transition into a subtle glass/solid navigation when scrolling.

Use backdrop blur and a thin border.

Mobile:

logo

theme toggle

hamburger

The mobile menu should open as a polished full-screen/large overlay menu.

HOMEPAGE HERO

Make the hero exceptional.

Do NOT use a conventional centered hero.

Use an editorial split composition.

Left:

Small eyebrow:

MODERN EDGE / ARCHITECTS • ENGINEERS • VALUERS • BUILDERS

Large headline:

Precision in Every Property.
Every Structure.
Every Detail.

Supporting text:

Modern Edge Architects and Engineers provides professional property valuation, construction, architecture and engineering solutions with a focus on precision, functionality and quality.

Primary CTA:

REQUEST VALUATION

Secondary CTA:

START A PROJECT

Right:

Create a sophisticated architectural visual composition using the uploaded logo/available assets and subtle architectural geometry.

If appropriate, use:

perspective lines

technical drawing details

grid systems

architectural geometry

subtle depth

Do NOT use cheesy construction graphics.

HERO ANIMATION

On initial load:

logo reveals smoothly

headline reveals line-by-line

text fades in

buttons appear

hero visual subtly moves

Keep animations fast and refined.

Do not create a long loading screen.

Respect prefers-reduced-motion.

FLOATING CTA

Create a subtle desktop floating CTA:

Need a Property Valuation?

REQUEST VALUATION

On mobile create a compact sticky bottom CTA:

REQUEST VALUATION

and a smaller:

CALL

Do not obstruct content.

HOMEPAGE INTRO

Immediately below hero create a short premium introduction.

Label:

ABOUT MODERN EDGE

Headline:

We design, evaluate and build with precision.

Explain briefly that Modern Edge is a multidisciplinary architecture and engineering company providing architecture, engineering, property valuation, construction, interior, landscape and related professional services.

Keep this section concise.

SERVICES PREVIEW

Create a premium editorial services section.

Featured services must be:

PROPERTY VALUATION

CONSTRUCTION

These two should visually dominate.

Secondary services:

Architecture
Civil Engineering
Interior Design
Landscape Design
Municipal Drawings
Real Estate
DPR
CAD 2D/3D Course

Do NOT make every service identical cards.

Use an editorial/staggered layout.

Property Valuation and Construction should receive significantly more visual space.

FINAL CTA

Create a clean CTA at the bottom of the homepage:

Your next project starts with a conversation.

Buttons:

REQUEST VALUATION

START A PROJECT

FOOTER FOUNDATION

Create a premium footer with:

Modern Edge logo

Short company description

Services

Company navigation

Contact

Social links

Do not over-design it yet.

IMPORTANT

At the end of this phase:

make sure the homepage is responsive

make sure light/dark mode works

make sure navigation works

make sure buttons route correctly

make sure there are no console errors

do not create fake content

do not invent company statistics

Prioritize visual quality over adding more sections.
